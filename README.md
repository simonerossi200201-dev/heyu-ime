> **先花 1 分钟看清它是什么（以及它适不适合你）：**
>
> **鹤羽音形 (HEYU)** 是一款用纯 Rust 从零编写、**100% 物理断网（二进制零网络 DLL 导入）**的个人效率输入工具。它把三件原本割裂的事融合成了一个随叫随到的桌面小胶囊：
> 1. **三种打字方案无缝切换**：你可以今天直接用零门槛的**【智能全拼】**整句连打，明天花 2 小时尝试击键减半的**【鹤羽双拼】**，两周后进阶四码免空格盲打的**【鹤羽音形】**（200+ 字/分），完全按你的节奏来；
> 2. **100% 本地离线语音转写与双光标协同**：搭载本地 Whisper 模型，无论是对着麦克风口述长文，还是**内录电脑里的网课/外语会议**实时转写，都不上传一字节到云端；开启独家的**【双光标独立转写】**后，语音自动往锁定的笔记窗口里写字，你的鼠标和键盘可以同时去别的窗口查资料、回消息，互不打架；
> 3. **加密个人词库与中/意/西/英四语伴学**：选中任何高频词句按 `Ctrl + Alt + N` 一秒收入个人词库（全盘 `HEYUENC1` 256-bit 认证密文保护），打中文时还能实时顺带显示意/西/英外语对照。
>
> ### ☕ 一句真诚的「劝退」提醒（请一定看完再决定要不要装）：
> 如果你只想要一个**“装上就永远不用管、自带云端大数据联想、也不需要看一眼说明书”**的默认傻瓜式输入法，那么 Windows 系统自带的微软拼音会让你省心很多——**真心建议你不用往下折腾了**。

> 鹤羽音形是为那些**对隐私有洁癖（绝不允许输入法联网上传）、每天有大量文字/会议/多语种输入需求、享受把工具调校成自己最趁手模样、并且愿意花 10 分钟翻一下图文说明书**的朋友准备的。如果你正好是同路人，它会成为你电脑里最安静、最快、最懂你的文字利器。

## ✨ 六大核心亮点

### 1. 三合一渐进式输入引擎（全拼 / 双拼 / 音形）
- **🚀 智能全拼**：Byte-Level 音节网格 + Viterbi 整句流式解码 + 超级简拼（如 `wmen` → `我们`、`srf` → `输入法`）。
- **⚡ 鹤羽双拼**：任意汉字仅需 2 键（声母 + 韵母），支持模糊音与整句连打。
- **🦅 鹤羽音形**：双拼 2 码 + 首末字根 2 码 = 4 码定字，四码唯一零空格自动上屏，支持反引号 `` ` `` 形码反查与双形记忆提示栏。

### 2. 100% 离线语音转写、双光标协同与 48kHz 专业录音棚
- **麦克风 & 电脑内录双音源**：按 `Ctrl+Alt+V` 麦克风听写，按 `Ctrl+Alt+B` 直接内录电脑里的网课/会议音频（支持 WASAPI 进程级音频隔离，只录指定会议软件声音）。
- **双光标独立转写**：将语音光标锚定在笔记软件后，您的键盘鼠标可自由切去其他窗口打字操作，语音转写结果通过后台无感注入锁定的笔记窗口，绝不抢占前台焦点。
- **智能纠错与口述英文缩写合成**：自动将口述的 `"a i"` / `"p p t"` / `"p d f"` 合成为 `"AI"` / `"PPT"` / `"PDF"`，支持自定义语音替换规则（最长匹配优先 + 冲突检测），并支持闲置自动释放显存/内存。

### 3. 自由拼装的灵动悬浮胶囊 & 15 款插画与经典皮肤
- **胶囊无级缩放与积木式组合**：支持 `70% ~ 160%` 整体无级缩放，14 项功能芯片（徽章、实时手速、全/双/音切换、简繁、标点、伴学、语音、录音棚、快速造词、词库、主题、设置）随心勾选组合，支持自定义圆形头像或用户名。
- **15 款高分屏主题（含 6 款原创手绘风插画皮肤）**：
  - 9 款经典质感皮肤（曜石流金、翡翠极光、深海星云、和纸、霜白、纸白、樱、薄荷、石墨）
  - 6 款治愈插画皮肤（🌸 春日花涧、🐕 柴犬暖阳、🐱 橘猫午后、🐼 竹林熊猫、🌿 森系苔原、🎐 晚风樱吹雪），自带 4x 超采样矢量边角微缩插画与无锯齿柔和圆角。

### 4. HEYUENC1 (256-bit) 认证密文个人词库
- **免密秒添、全盘加密**：复制文字后按 `Ctrl+Alt+N`（或在设置中心词库页）免密一键添加词条，自动推导编码并置顶；底层采用 `PBKDF2-HMAC-SHA256 (120,000 轮) + 256-bit CTR + HMAC-SHA256` 认证密文存储，查看全表或更换电脑设备时强制验证主密码。
