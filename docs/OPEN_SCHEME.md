# 鹤羽开放音形方案说明 (`docs/OPEN_SCHEME.md`)

[`data/open/heyu_open_sys.tsv`](../data/open/heyu_open_sys.tsv) 是由 [`tools/build_open_table.py`](../tools/build_open_table.py) 完全基于开放许可数据（Unicode Unihan 数据库 `Unicode License v3` + 结巴分词词频表 `MIT License`）自动构建的独立双拼+部首笔画四码方案，不依赖任何第三方私有或受限字根表。

---

## 一、四码结构 (`音1 + 音2 + 形1 + 形2`)

1. **前两码（双拼声韵码）**：
   - 采用通用双拼键位映射（与 Windows 微软拼音内置双拼方案兼容），零声母字采用首字母 + 全拼末字母规则。
2. **第三码（形1 · Unicode 康熙部首码）**：
   - 直接读取 Unicode Unihan `kRSUnicode` 字段中的标准康熙部首编号（1–214），按部首语义与首音映射到 `a–z`。
3. **第四码（形2 · Unicode 末笔与构件笔画码）**：
   - 直接读取 Unicode Unihan `kStrokes` 笔顺序列与 `kTotalStrokes` 总笔画数，将基本笔形（横1、竖2、撇3、点4、折5）与剩余笔画数独立映射至 `a–z`。
4. **多字词编码规则**：
   - 二字词：取首字前两码 + 次字前两码（`AaBb`）
   - 三字词：取前两字声母码 + 末字前两码（`ABCc`）
   - 四字及以上词：取前三字声母码 + 末字声母码（`ABCZ`）
