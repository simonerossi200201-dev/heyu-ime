# 鹤羽离线语音输入使用与安全说明 (`docs/VOICE.md`)

`heyu-voice.exe` 是鹤羽音形内置的**100% 纯离线、零网络导入、支持中/英/意/西四语**的本地语音输入引擎。

---

## 一、核心特性与使用方法

1. **全局快捷键一键说写（默认 `Ctrl + Alt + V`）**：
   - 在任何输入框中按下 **`Ctrl + Alt + V`**，光标旁会浮现轻巧的 **「🎙 聆听中」** 音量胶囊。
   - 说完话后**停顿约 1.2 秒**（或再次按下 `Ctrl + Alt + V`），引擎立即在本地完成识别并将文字直接输入到当前窗口；按 `Esc` 可随时取消本次录音。
2. **中 / 英 / 意 / 西 四语无缝支持**：
   - 默认设置为 **「跟随输入法」**：当输入法处于中文模式时识别中文（自动输出简体中文与规范标点），处于 `IT` / `ES` / `EN` 模式时自动对应识别意大利语、西班牙语或英语；也可在「设置中心 › 语音输入」中设为「自动检测」或固定语言。
3. **常驻显存极速响应（RTX GPU CUDA 加速）**：
   - 首次加载模型后，模型常驻于本地显存/内存中。在 RTX 5060 Ti 上实测 5–6 秒语音仅需 **130–200 毫秒**即可完成识别上屏（实时率 RTF ≈ 0.03，比说话速度快 30 倍）。

---

## 二、隐私与安全保障（可公开验证）

1. **二进制零网络能力（PE 导入表级验证）**：
   - [`tools/security_audit.py`](../tools/security_audit.py) 对 `heyu-voice.exe`、`voice-runtime/whisper-cli.exe` 与 `voice-runtime/whisper.dll` 的 Windows PE 导入表进行静态审计：**0 个网络库导入**（无 `ws2_32.dll`、无 `winhttp.dll`、无 `wininet.dll`），从物理上不具备任何联网或建立 Socket 的能力。
2. **音频仅留存内存，阅后即焚**：
   - 麦克风音频通过 Windows 原生 `winmm.dll` (`waveIn`) 直接采集至内存缓冲区，识别完成后或按 `Esc` 取消时立即清零释放，绝不向磁盘写入任何录音日志或识别历史。
3. **开源许可与模型来源透明**：
   - 推理引擎采用 [`ggml-org/whisper.cpp`](https://github.com/ggml-org/whisper.cpp)（**MIT 许可证**），模型权重采用 OpenAI Whisper 多语种量化权重（**MIT 许可证**）。
   - 模型通过独立脚本 [`tools/fetch_voice_model.ps1`](../tools/fetch_voice_model.ps1) 从 Hugging Face 官方仓库（美国托管）下载，并强制执行硬编码 **SHA-256 哈希校验**，校验不通过立即拒绝使用。

## 三、可选模型对比

您可以在「设置中心 › 语音输入」中一键切换或下载以下模型（存放于 `%APPDATA%\HEYU\models\`）：

| 模型名称 | 体积 | 特点与适用场景 |
| :--- | :--- | :--- |
| **`large-v3-turbo-q5_0`（默认推荐）** | ~547 MB | **准确率最高**，中/英/意/西四语识别最精准，GPU 下仅需 0.15–0.3 秒 |
| `medium-q5_0` | ~514 MB | 高准确率备选模型 |
| `small-q5_1` | ~181 MB | 轻量均衡，适合无独立显卡的轻薄本 CPU 运行 |
| `base-q5_1` | ~57 MB | 超小体积，极速响应 |
